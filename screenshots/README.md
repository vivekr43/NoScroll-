# Screenshots

This folder contains screenshots used in the README.

## Files needed

| Filename | Description |
|---|---|
| `popup_dashboard.png` | The popup dashboard showing stats (Home tab) |
| `interrupt_screen.png` | The full-screen interrupt/warning overlay |
| `settings.png` | The Settings tab showing time limit options |
| `banner.png` | Wide banner image for the README header |

## How to capture them

1. Load the extension in Chrome (`chrome://extensions/` → Load unpacked)
2. Visit Instagram or YouTube Reels
3. Open the extension popup and screenshot each tab
4. For the interrupt screen: trigger it by scrolling past your limit (or temporarily lower the limit to 1 min in Settings to trigger it quickly)
